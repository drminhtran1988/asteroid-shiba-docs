# Salvage Run

Entry to Asteroid Shiba is paid. **Salvage Run is the way in without paying.**

Every day, explorers who don't have a Scanner go out into the debris field together, and a number of them come back with a working **Scanner Level 0**, recovered from the wreckage. It costs nothing to join and it runs again tomorrow.

## Who can join

<img src="../.gitbook/assets/lv0-explorer.png" alt="An explorer with no Scanner" width="140" align="right">

**Every new player without a Scanner.** There's no waiting period, no minimum account age, no purchase history required. Open the game, join the run.

## How many Scanners are recovered

**It depends on how many explorers go out.** The more people join a run, the more Scanners are recovered from it — a busy night salvages more than a quiet one.

The exact number for tonight's run is **published in the Salvage Run screen** before the draw, so you always know what you're playing for before you commit.

## How a run works

```
Join the run (free) → the field fills up → the draw → recovered Scanners are handed out
```

1. **Join.** One tap. You're counted in tonight's run.
2. **Watch the field.** The screen shows how many explorers are out there and how many Scanners are up.
3. **The draw.** Winners are picked at the end of the run.
4. **Claim.** Winners get their Scanner Level 0 and can start hunting straight away.

## What you win

A working **Scanner Level 0** — the same tier a paying player gets, with the same five signals a day, the same active slot, the same [storage](storage.md), and the same [$25 withdrawal limit](limits.md). A recovered Scanner is not a trial: it's the real thing, and you keep it.

## If you don't win

Nothing is lost. Join the next run. There's one every day, and joining costs nothing.

{% hint style="info" %}
Salvage Run exists so that not having $10 never means not playing. If you'd rather skip the wait, [Scanner Level 0](overview.md) is available to buy at any time.
{% endhint %}
